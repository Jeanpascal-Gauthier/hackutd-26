# Firewatch — team rules

## Folder ownership

- `headset/` — Person A
- `server/` and `data/` — Person B
- `agent/` — Person C
- `console/` — Person D
- `shared/` — everyone. Change only after telling the team.

## Rules

- Only edit files in your owner's folders.
- Never reformat or refactor other folders.
- Don't add root dependencies without asking.
- Keep commits small.
- `npm run dev` must still work before committing.
